# Vue 渐进迁移

第一阶段：竞争力对比中的本品、左侧竞品、右侧竞品编辑表格，共用
`config-editor.js` 的 Vue 3 组件。组件直接更新现有 snapshot / ladder 数据结构，
由原来的 Python API 保存。`config-editor.css` 只作用于组件区域。

Vue 3.5.22 固定保存在 `vendor/vue`，不依赖 CDN 或用户安装 Node；现有
PyInstaller 配置会收集整个 ui 文件夹。主导航、PPT 原文解析、配置阶梯页面、
赋值规则和结果导出仍使用现有实现，后续逐步迁移。

第二阶段：PPT 展开后的本品配置校对表格已接入共用组件，包含版型改名、
指导价、占比、续航备注及配置依据编辑。改名同步 values / links / base，
保存前校验输入有效性。PPT 页面选择与原文解析面板仍为原实现。

第三阶段：竞争力对比里的赋值规则表格已接入 Vue，固定金额、动态分档、
排除项和规则备注均沿用原有数据结构与保存流程。

第四阶段：PPT 导入草稿中的版型卡片已接入 Vue，版型名称、比较基准、价格、
配置原文和增删版型操作继续写入原有 pptDraft 数据结构。

第五阶段：独立的配置阶梯检查页面也使用同一套 Vue 配置编辑表格，
与竞争力对比中的竞品编辑共用阶梯数据、配置联动和座椅/屏幕/后视镜控件。

第六阶段：增加侧边栏隐藏/显示控制，状态保存在浏览器本地；侧边栏收起后仍可从左上角恢复。

第七阶段：配置阶梯页面的版型选择与比较基准编辑区接入 Vue，导出与预览继续复用
原有 `stagePlan()` 数据结构。

第八阶段：配置阶梯按指导价升序自动生成逐级比较关系，最低价版型为基础配置，
后续版型默认以上一个更低价版型为基准；停用版型后会自动重连阶梯。

验证：在项目根目录启动 `python3 -m http.server 4174`，打开
`http://127.0.0.1:4174/tests/vue-editor-preview.html`。此页使用独立测试数据，
支持切换本品、竞品适配器；顶部显示修改后的模型。检查平台、座椅、屏幕、
后视镜联动、待定值保留、数字输入和紧凑布局。该预览不连接保存接口。
