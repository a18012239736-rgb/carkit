# carkit v0.2.2 · 全新汽车产品分析工作台

Windows 单文件版，下载发布附件 `carkit.exe` 后双击运行，无需安装 Python。界面需要 WebView2，抓取需要 Edge 或 Chrome。

## 2026-10-22 PPT 导入修正（版本号不变）

- 支持“核心配置：”“较标准型+：”“相对标准型＋：”等阶梯写法；优先匹配完整版型名称，简称结合当前列前缀匹配，存在歧义时继续提示人工核对。
- 保留名称带“+选装”的独立列，避免遗漏版型。
- 同页出现指导价和结算价时，优先读取指导价行；按元／万元标记换算，未标单位且金额大于等于10000时按元换算并提示核对。
- 原有文本阶梯、并排卡片和原生表格导入方式保留。9列阶梯样例已通过解析、展开、隔离保存和重载，980项本地回归测试通过。
- 本次修正导入结构与价格识别；未完全映射的配置缩写仍保留在原文待核清单中。
- 继续使用 v0.2.2，补充修正源码见[主分支](https://github.com/a18012239736-rgb/carkit/tree/master)，原发布标签保留。

## 全新界面

- 统一为浅色工作台，重新设计导航、页面层级、按钮、表单和编辑表格。
- 配置阶梯按“选择车型 → 确认版型 → 预览与导出”展开，明确输出版型、指导价及比较基准，集中展示预览和导出操作。
- 竞争力对比分为左右车型、人工版型配对、底价和结果区，导出与方案保存集中到结果区，待核清单和判定明细按需展开。
- 本品配置、赋值规则和设置与帮助可从侧栏直接进入；页面显示当前所在位置，并保留明确的返回入口。
- 历史车型、展示设置、本地导入和规则说明默认折叠，减少同时出现的信息。
- 配置编辑表与赋值表支持固定表头和配置名称列，宽表格在各自区域滚动，适配最小 1024×700 窗口。

## 交互改进

- 搜索支持回车，读取期间禁用重复操作，失败后恢复搜索入口。
- 顶部流程状态随车型读取、阶梯预览、导出和对比结果更新。
- 修改版型、比较基准或展示清单后，旧预览失效并提示重新生成。
- 保留 Markdown、Excel 导出、对比方案存取、原文依据和选配展示。

原始数据、保存的方案与自定义规则沿用现有格式；本次界面改版不调整赋值计算口径。

## 验证

- 972 项本地全量回归测试通过，其中包含 109 项界面与相关回归检查；IDE 错误检查通过。
- 使用项目历史样本检查了 7 版型阶梯、版型配对与金额结果、Markdown／Excel 导出、保存方案、本品录入及导航收放。
- 浏览器检查覆盖 1360×900 和 1024×700 窗口；Windows 发布流程另行执行全量回归、单文件打包与独立目录启动检查。
