# carkit v0.2.3 · 阶梯图与座椅配置对比优化

Windows 单文件版，推荐下载 **carkit-0.2.3.exe**，双击运行即可。无需安装 Python；界面需要 WebView2，抓取需要 Edge 或 Chrome。`carkit.exe` 为同内容的兼容文件名，任选一个下载。

## 配置阶梯

- 增配与减配分别显示在“基准版型+：”“基准版型-：”下；整项移除直接列配置名，不再显示“无（配置）”。
- 部分功能减少只列丢失功能；方向数、屏幕尺寸等明确规格降低归入减配，并保留基准值方便核对。
- “选装配置”标题加入底色，与基本配置和增减配标题统一。

## 座椅识别与展示

- 主副驾使用 `+` 连接，共用一组对比括号；向数相同只写手调／电调，方式相同只写向数，未变化座位省略。
- 腿托、腰托作为独立配置展示，区分主驾和副驾，不计入座椅方向；选装不计入标配。
- 修复明确总向数旁有独立支持子项时的漏识别，以及全角分隔符导致调节方式识别不完整的问题。
- 座椅文案简化不改变原始数据和赋值口径；前后、靠背各计2向，高低按原表注明方向，明确总方向数直接保留。

## 自动打包

- Windows 构建自动按程序版本生成 `carkit-<版本号>.exe`，同时保留兼容文件名 `carkit.exe`。
- 标签发布前检查标签、程序和包元数据版本一致；构建运行完整回归，并在独立目录验证带版本号程序启动。
- 手动 Run workflow 保持仅构建附件，推送版本标签才自动发布 Release。

## 验证

- 本地完整回归 **1,018 项通过**。
- 使用汽车之家已有原表核对启源 Q05、启源 A06、元 PLUS、元 UP、星瑞 L PLUS、蔚来 ES8、MG 07，共 **46 个版型**。
- 通过 **234 组阶梯对比、2,116 组竞争力文案对比**，原始配置文件保持不变。
