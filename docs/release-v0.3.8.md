# Carkit v0.3.8 · 深色侧栏工作台与全面稳定性修复

- 工作台升级为**深色固定窄侧栏 + 浅色高信息密度内容区**，表格与数据区对比度更清晰，并支持切换为底部浮动命令栏或收起。
- 竞争力对比结果新增顶部**核心结论 KPI 摘要带**，竞争力对比表按正负动态着色（正值绿、负值红），不再对负综合竞争力误标绿底。
- 配置阶梯卡片新增**相对基准价差胶囊**、精简版型移动按钮与暖色选装统计；配置编辑器新增**已修改单元格标记**与分类项数显示。
- 系统稳定性与引擎判定全面修复（涵盖配置映射、座椅/屏幕/USB/悬架/尾门/续航与赋值边界、PPT 导入识别、飞书与 GitHub 更新校验以及前端竞态保护等 49 项修复）。

本次更新沿用原有工作目录和配置数据。

Windows 提供安装版（`carkit-0.3.8-setup.exe`，支持程序内下载并安装后续更新）和便携版（`carkit-0.3.8.exe` / `carkit.exe`）。Mac 提供 Apple 芯片（arm64）DMG，将新版拖入「应用程序」替换。macOS 安装包尚未经过 Apple 公证。

此前版本见 [v0.3.7 更新记录](https://github.com/a18012239736-rgb/carkit/releases/tag/v0.3.7)。
