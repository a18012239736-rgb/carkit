# carkit v0.3.2 · 安装版支持程序内更新

- GitHub 发布的版本号高于当前版本时，程序才提示更新并提供下载。同版本显示已是最新。
- Windows 安装版先验证发布清单签名，再下载并校验安装包。确认保存工作后，安装器等待旧程序退出，完成安装后按原工作目录重新打开。
- 现有便携版用户需先运行 `carkit-0.3.2-setup.exe` 安装一次。继续使用便携版时，可以下载并手动启动新版 EXE。
- GitHub 检查或下载失败时，可通过设置中的飞书更新页下载 Windows 程序。

此前版本见 [v0.3.1 更新记录](release-v0.3.1.md)。
