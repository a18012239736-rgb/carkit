# carkit v0.3.1 · 程序更新与使用反馈

2026-11-03

Windows 单文件版，推荐下载 **carkit-0.3.1.exe**。无需安装 Python；界面需要 WebView2，抓取需要 Edge 或 Chrome。`carkit.exe` 为同内容的兼容文件名，任选一个下载。

## 检查与下载更新

- 启动后异步检查官方 GitHub 最新正式 Release，不阻塞配置工作；“设置与帮助”提供手动检查、更新说明与官方发布页。
- Windows 单文件版同时比较版本号与程序 SHA256，可识别同版本补丁；不提供降级。源码或非 Windows 运行仅提供版本信息及发布页。
- 点击“下载新版”后选择新的 exe 保存位置，显示下载进度并校验大小、SHA256 和可执行文件头。失败时不产生可用的完整安装包，不覆盖正在运行的程序或已有文件。
- 下载成功后请保存当前工作、关闭旧版，再启动新版；使用自定义数据目录时沿用原启动参数。程序不自动替换、运行新版或强制重启，车型资料、赋值规则及已保存方案继续保留。
- 旧版没有更新入口，首次需手动下载此版本；之后可使用程序内检查与下载。未提供校验摘要的发布包仅提供官方发布页入口。

## 文字与截图反馈

- 设置页和侧栏新增“反馈使用情况”。可填写标题、问题描述，并预览或移除最多3张 PNG/JPEG 截图（每张不超过5MB，总计不超过10MB）。
- 内容先保存在本机工作目录的 `反馈/` 中；确认可公开后打开官方 GitHub Issues 草稿，由使用者登录、上传截图并最终提交。准备草稿不表示反馈已经提交。
- 正文过长时可复制完整内容到 GitHub；截图不会自动上传。程序只附当前版本和系统类型，不自动收集车型资料、用户名、本机路径或凭据。

## 验证

- 本地完整回归 **1,120 项通过**，覆盖版本比较、同版本补丁、下载校验及失败保护、反馈输入与附件限制、公开确认和界面交互。
- 笔记本窗口尺寸下验证更新卡片、反馈弹窗居中与滚动。
- Windows 发布流水线运行完整回归、打包单文件程序，并在独立目录验证启动后发布附件。
