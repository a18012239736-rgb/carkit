# 产品小工具 v0.2.1

Windows 单文件版，下载发布附件 `carkit.exe` 后双击运行；无需安装 Python。抓取需要 Edge 或 Chrome，界面需要 WebView2。

本页记录 v0.1.19 之后的更新，原 v0.1.19 更新日志保留。

## 2026-10-19 补充修正（版本号不变）

- 配置阶梯卡片的“基础配置：”改为“基本配置：”，“相对 基准版型：”改为“基准版型+：”。
- 仅修改文字，原来的灰底、字号、间距和布局保持不变；比较基准、卡片换位、导出顺序及赋值计算不变。
- 增加标题文字、特殊字符转义与换位后基准不变的回归检查，887项本地测试通过。
- 程序包继续使用 v0.2.1，补充修正源码见[主分支](https://github.com/a18012239736-rgb/carkit/tree/master)；原发布标签及下方首次发布记录保留。

## 新增

- 保存和继续对比方案：保存双方配置、人工配对、底价、本轮规则、展示偏好、原文依据及结果。重新打开可查看历史结果，在独立工作副本中修改、重算并另存，不覆盖原方案、原始抓取或全局规则。重算沿用方案规则，但使用当前程序的识别和计算算法。
- 原文依据与待核清单：在配置项判定明细中查看双方原始配置、标配／选配、本轮采用值、计数说明和赋值规则。集中提示待定、未映射、数量未知及缺赋值规则等问题；提示不自动补配置或改金额。旧数据没有原文时明确提示，不补造来源。
- 配置阶梯卡片支持“左移／右移”，方便并排查看；只改变当前展示位置，不改变比较基准和导出顺序。
- 本品 PPT 导入识别“540°透明底盘”“540度透明底盘”等写法，对应540影像。
- 本品草稿卡片和完整配置表新增“选装配置”，每行一项，按版型独立维护、不自动继承。明确标为选装的正文也单独保留；选装可在对比结果、Markdown、Excel及保存的方案中展示，不作为标配、不参与多／少和赋值计算。

## 展示修正

- 配置展示清单改为“勾选显示、取消隐藏”，分类按钮改为“全选显示／全部隐藏”，保留搜索、分类和选配提示。
- 恢复驾驶辅助影像、辅助驾驶路段、座椅记忆、无线充电功率、内后视镜、近光灯光源、中控屏幕尺寸及前排座椅功能的默认展示，按原有规则合并描述，避免来源行被隐藏后遗漏相关信息。
- 内置默认隐藏项由217项调整为209项。已有本地自定义清单继续优先，不强制覆盖用户选择；可在“展示的配置”中自行恢复。已有阶梯需重新查看或导出。

展示清单、卡片移动及选装展示不改变现有赋值口径，原始抓取数据保留。
