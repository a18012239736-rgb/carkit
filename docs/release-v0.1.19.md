# 产品小工具 v0.1.19

Windows 单文件版，下载发布附件 `carkit.exe` 后双击运行；无需安装 Python。抓取需要 Edge 或 Chrome，界面需要 WebView2。

## 更新

- 统一主要气囊计数：主副驾各1个，侧气囊前后排各2个，头部气囊前后排各1个，前排中间气囊1个，膝部每个标配项1个。选配不计，同类别名去重，不预设最低数量；每气囊350元不变。
- 修复副驾娱乐屏别名、座椅金额尾注、选配360影像误作标配等实际车型样本问题。
- 修复前后排无线充电识别；已注明≥40W按快充350元、显示50W，低于40W按慢充100元、显示慢充。不明功率不凭空补写50W。
- 明确标注前排且未限定主驾的座椅功能按主副驾都有处理；限定主驾或副驾的功能保留对应位置。
- 空气／魔毯悬架按软硬与高低两项合计，不重复赋值。氛围灯统一按单色／多色显示和计价。
- 激光雷达线数默认不展示，仍不参与赋值；数量与品牌保留。
- 原地更新未手改的历史自动结果，保留不同的人工修正、价格及版型顺序；原始抓取数据不变。
- PPT前排中间／中央气囊和主副驾膝部气囊识别补齐；明确总数不重复叠加同句组成，基础数量不明仍提示核对。

## 验证

本地701项回归测试通过；136组车型—能源样本、662个版型回放一致。发布流程另在 Windows 完成回归、单文件打包及隔离目录启动验证后生成可下载程序。

未确认数量的后排中央、防下滑、座垫式等特殊气囊继续保留原始描述，不擅自加入已确认主要项小计。上市前配置未填写的车型不补猜。
