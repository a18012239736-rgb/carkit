# Carkit v0.3.6 · 液态玻璃工作台

- 工作台采用浅色液态玻璃样式，沿用绿色强调色。默认左侧菜单保留图标、文字和原来的分区。
- 可在左侧文字菜单和底部图标停靠栏之间切换。底部模式悬停显示名称，当前页以绿色圆点标记；程序记住选择的位置。
- 配置阶梯的卡片可原位展开该版型的完整配置，收起后回到原浏览位置。基础版型使用浅绿色高亮。
- 程序内的「打开飞书更新页」已切换到新文档。

本次更新沿用原有工作目录和配置数据。

Windows 安装版可通过程序内的「下载并安装」升级；便携版下载新版 EXE。Mac 请按芯片选择 Apple 芯片（arm64）或 Intel 芯片（x86_64）的 DMG，将新版拖入「应用程序」替换。无法访问 GitHub 时，可从飞书更新页下载。macOS 包尚未经过 Apple 公证。

此前版本见 [v0.3.5 更新记录](https://github.com/a18012239736-rgb/carkit/releases/tag/v0.3.5)。
