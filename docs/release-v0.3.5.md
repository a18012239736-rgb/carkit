# Carkit v0.3.5 · 赋值规则分类

- 「赋值规则」现在按照「修改配置」中的汽车之家配置分类和顺序分组，便于按系统查找和调整配置金额。
- 每组配置仍使用原有赋值规则、金额和参数；分类只改变页面展示，不改变计算结果或保存数据。

本次更新沿用原有工作目录和配置数据。

Windows 安装版可通过程序内的「下载并安装」升级；便携版下载新版 EXE。Mac 请按芯片选择 Apple 芯片（arm64）或 Intel 芯片（x86_64）的 DMG，将新版拖入「应用程序」替换。无法访问 GitHub 时，可从公司飞书更新页下载。macOS 包尚未经过 Apple 公证。

此前版本见 [v0.3.4 更新记录](https://github.com/a18012239736-rgb/carkit/releases/tag/v0.3.4)。
