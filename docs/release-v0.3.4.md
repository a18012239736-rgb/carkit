# Carkit v0.3.4 · 工作台界面更新

- 改用顶部导航，在「配置阶梯」「竞争力对比」「设置与帮助」之间切换，为配置表和阶梯卡片留出更多横向空间。
- 将「本品配置」和「赋值规则」放到「竞争力对比」的子页签中，准备数据、配对版型和调整规则可在同一工作区完成。
- 统一按钮、表格和面板的样式与间距，改善不同窗口大小及系统缩放下的显示。
- 更新提醒支持「忽略此版本」：重启后保留选择，出现更高版本时再次提醒。可在「设置与帮助 → 程序更新」恢复提醒，也可随时手动检查和下载新版。

本次更新沿用原有配置识别、赋值算法和工作数据，可继续使用原工作目录。

Windows 安装版可通过程序内的「下载并安装」升级；便携版下载新版 EXE。Mac 请按芯片选择 Apple 芯片（arm64）或 Intel 芯片（x86_64）的 DMG，将新版拖入「应用程序」替换。无法访问 GitHub 时，可从公司飞书更新页下载。macOS 包尚未经过 Apple 公证。

此前版本见 [v0.3.3 更新记录](https://github.com/a18012239736-rgb/carkit/releases/tag/v0.3.3)。
