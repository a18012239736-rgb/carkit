# carkit — 车型配置对比工具

把「5C 配置抓取」和「赋值对比」两个汽车产品工作流程序化的独立工具。
最终形态：**Windows 独立 exe + GUI**（pywebview），无需 Claude/MCP 环境即可运行。

## 功能链

```
抓取(汽车之家配置页) → 竞品阶梯(41项×N版型) → 自产品快照编辑 → 赋值表(pjy规定金额)
                                                    ↓
                              对比结果: BACKUP表(多/少/配置优势/拉平指导价优势/综合竞争力)
                                       + 41项判定明细(多/少/同/豁免/不计)
                                                    ↓
                              导出 md / xlsx ；5C 五段制 md 导出
```

## 架构

- `engine/` — 纯 Python 引擎，零 GUI 依赖（解析/映射/diff/赋值/渲染），可被 exe、CLI、外部脚本共用
- `engine/rules/` — 随包规则数据（41项清单、豁免规则、别名映射），热更新不重打 exe
- `api/` — pywebview js_api 桥（JSON 进 → engine → JSON 出）
- `ui/` — HTML/CSS/JS 前端，侧边栏导航 6 页（抓取/阶梯/快照/赋值/对比/设置）
- `cli.py` — 命令行入口（开发、回归测试用）
- `tests/golden/` — 真实数据回归夹具（T19NG vs 启源Q05）
- `build/` — PyInstaller Windows 打包脚本（**必须在 Windows 实机跑**）

## 铁律（程序内置，不可绕过）

1. 版型配对必须由使用者手动指定，绝不按价格自动配对
2. 映射不中的配置项标 `[待映射]`、缺赋值项标 `[待赋值]`，交人裁决，程序不脑补
3. 汽车之家无该配置行 = 该车没有此配置
4. 选装 ○ 不计为「有」；[待定] 项不计入多/少
5. 无赋值表时只出纯差配清单，金额行显示「待赋值明细表」

## 数据敏感性

本仓库存含未发布产品策略数据（T19NG 快照、赋值金额），**必须保持 private**，不得公开或授权外部访问。

## 环境

- 开发：macOS，python 3.12
- 运行（目标机）：Windows 10/11，需已装 Edge 或 Chrome（抓取用），WebView2 Runtime（GUI 渲染，系统一般自带）

## 快速开始（开发态）

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -e .            # 安装依赖
pytest tests/               # golden 回归
python cli.py ladder tests/golden/raw-Q05-汽车之家全表-2026-09-11.json
python cli.py diff --snapshot <快照.json> --ladder <竞品阶梯.json> --pairs "基础型:405Max,舒适型:506Max"
```

## 第一部分：配置阶梯

启动 `python app.py` 后进入“配置阶梯”：输入车型名称、车系编号或汽车之家配置页网址，也可填写年款（留空默认最新年款）。程序会在汽车之家主站搜索并读取完整配置表，自动取消隐藏相同参数/暂无内容，并校验版型列数、关键配置行和指导价。网站验证时在弹出的浏览器完成验证，再点“验证后继续读取”。Windows 打包版默认使用桌面 `Codex` 文件夹作为工作目录。

如需把已生成的 `dist/carkit` 复制到桌面，可运行 `build/deploy_desktop.ps1`。脚本只覆盖程序文件，不删除桌面 `Codex` 中已有的抓取数据和结果。

读取完成后，在版型列表中勾选要输出的版型。第一行作为基本配置；后续版型必须选择一个已经排在前面的版型作为比较基准，程序只输出相对基准的变化，继承项不重复。最后点击“导出配置阶梯 Markdown”。原始完整表与 Markdown 会保存到工作目录的 `raw/` 和 `阶梯/`。

程序不会把抓取失败、隐藏行或选装行当成标配：选装会单独写入引用块，完整表校验失败会停止导出并给出原因。
